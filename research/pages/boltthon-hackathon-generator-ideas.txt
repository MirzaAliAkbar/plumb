 Boltthon
 Overview
 Core Product: 
Boltthon is your launchpad — a hackathon idea generator powered by bolt.new that transforms concepts into build-ready prompts in seconds. Hackathons start with brilliance, not brainstorming.
 Product: Web App & API
 Market Type: B2C for hackers & students, B2B white-label for organizers and schools
 Technologies: OpenAI GPT-4 Turbo, Supabase, Netlify
 Team: Bolt coders since 2024, James is seasoned founder Y Combinator alumni, Jose is the CEO of brandvirality, expert on marketing, growth the user base into 300k users in 4 months.
 Problem 
Most hackathons waste precious hours stuck in brainstorming. Teams struggle to align on ideas, lose momentum, or settle for uninspired projects. Generic idea lists don’t adapt to themes or skills — so creativity stalls before the building even starts.
 Solution 
 Boltthon transforms brainstorming into a launchpad: generate smart, tailored hackathon prompts that match event themes, trending tech, and your team’s skillset. Get unstuck in seconds and start building prize-worthy hacks on day one.
 Market Validation 
 $200M+ global hackathon & dev event industry
 1M+ hackathon participants annually worldwide
 67% of participants say ideation is their biggest blocker (I posted a question on X)
 Core Selling Points 
 AI-powered, theme-specific prompt generation
 Build-ready idea packs with use cases, tech stack suggestions, and pitch outlines
 White-label portals for organizers, schools, and sponsors
 Saves hours and supercharges team creativity
 Talking Points 
 Hack smarter: spend time building, not stuck brainstorming
 Fresh, feasible ideas aligned with real trends and sponsor APIs
 Better projects mean happier organizers, judges, and sponsors
 Scalable for universities, bootcamps, dev clubs, and global hackathons
 Audiences 
 Student hackers & indie devs
 Hackathon organizers & sponsors
 Universities, bootcamps, coding schools
 Top 3 Features 
 Smart Prompt Generator — Instantly create tailored hackathon ideas.
 Idea Packs — Build-ready cards with suggested stacks and user stories.
 White-Label Portal — Organizers embed Boltthon into their event platform.
 Inspiration
 We’ve seen too many talented hackers waste hours stuck in the ideation spiral. Boltthon exists to spark brilliant ideas instantly — so everyone can build bolder hacks, win more prizes, and push creative limits.
 What It Does
 Smart Prompts: AI generates unique hackathon-ready ideas.
 Theme Matching: Aligns prompts with event themes and sponsor APIs.
 Idea Packs: Includes user stories, tech stack suggestions, and pitch outlines.
 Save & Share: Save ideas, share with teammates, and refine collaboratively.
 White-Label: Organizers integrate Boltthon for a branded experience.
 How We Built It
 Main Technologies: OpenAI GPT-4 Turbo, Supabase, react, netlify, Stripe
 Technology Stack 
 Frontend: React for cross-platform web development.
 Database: Supabase for database, authentication, and file storage.
 Infrastructure: Supabase erverless edge functions for scalable story generation.
 Hosting: Netlify for deployment and hosting.
 Figma: Figma for design.
 AI Integration: OpenAI GPT-4 for story generation, DALL-E 3 for artwork.
 Version Control: GitHub for version control, backups, and collaboration. 
 Error Handling: Sentry automatically detects and notifies you of critical performance issues.
 Domains: iONOS/ENTRI for domains. 
 How We Built It 
 Built the prompt engine with GPT-4 Turbo and custom templates
 Integrated Supabase for user auth and project saving
 Deployed serverless functions for fast idea generation
 Connected Stripe for payments and credits
 Deployed the app on netlify for instant scaling
 Tested with real hackathon organizers and student devs
 Challenges We Ran Into
 Tuning prompts for different event themes and skill levels
 Ensuring fast generation speeds under load
 Designing a white-label experience that’s easy to integrate
 Accomplishments We’re Proud Of
 First working version live in under 2 days
 Used by +100 users on the first 2 days
 What We Learned
 Hackers want tailored ideas, not generic lists
 Organizers love tools that boost project quality
 Prompt engineering is key for useful, actionable ideas
 What’s Next
 Add team matchmaking based on idea packs
 Launch mobile app for on-the-go brainstorming
