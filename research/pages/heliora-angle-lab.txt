 Heliora Angle Lab
 Explore circular angles with keyboard-friendly sliders, a live diagram and text feedback. A free, account-free lesson using synthetic positions, with no WebGL or birth data required.

 Actual Angle Lab browser capture: A=0°, B=94°, orb=5°. Synthetic positions; keyboard controls and text feedback. 
 A specific barrier to learning
 Heliora Angle Lab is a free browser lesson for beginners learning circular separation and tolerance. Static diagrams make it hard to see what changes when a position crosses zero degrees. A complex 3D chart also adds setup and navigation demands before a learner can practise one concept.
 What the learner can do
 Move two labelled markers with native sliders or the keyboard, choose an exact-angle preset, and compare the shortest separation with an adjustable tolerance (called an orb in the lesson). An SVG diagram and numeric text describe the same result. No account, payment, birth details or student records are needed. The lesson makes no requests to an AI model and needs no WebGL.
 Before and after
 Before: positions 350 degrees and 10 degrees can look 340 degrees apart when simply subtracted. After: change the two sliders and the lesson shows a shortest separation of 20 degrees. A second exercise starts with A at 0 degrees and B at 94 degrees: a 5-degree tolerance includes a 90-degree square; a 3-degree tolerance excludes it. These are demonstrable interactions, not measured claims of learning improvement.
 Event contribution and existing foundation
 The older Heliora Studio celestial application and brand predate this event. This entry is the separate HTML, CSS, SVG and JavaScript Angle Lab teaching page published on 14 November 2026, during the AccessED, LaunchPad Hacks and Code for Change build windows (commit 65d70f00dd8a6ef61b0127854d1d71e50e169a2a). It does not claim the older 3D app as new work. The same Angle Lab project is entered in AccessED Hacks, LaunchPad Hacks and Code for Change; this is disclosed reuse, not an exclusive build. The lesson is also a public portfolio teaching example, and its optional custom-page service is separate from the free demo.
 Build, challenges and lessons
 Native range controls, text outputs and a dynamically described SVG keep the mathematical state visible without relying on colour alone. The central challenge is circular wraparound and explaining a tolerance boundary without confusing it with an exact angle. Small examples and explicit numeric feedback make these rules inspectable. The code is available in two public files: heliora-angle-lab.html and heliora-angle-lab.mjs.
 Verification and limitations
 Browser checks on 15 November verified 350/10 wraparound, the 94-degree tolerance example at 5 and 3 degrees, and arrow-key adjustment of Marker B. The SVG description updates with the same values. This is not a full screen-reader or accessibility audit, and no external learner study has been conducted. JavaScript is required for interaction. Aspect names come from the original teaching context; the app demonstrates geometry with synthetic positions, not astrology predictions, live astronomy or scientific evidence for astrology. Orb conventions vary.
 Try it
 Open the free demo. Set Marker A to 350 and Marker B to 10. Then set A to 0 and B to 94; compare allowed orb 5 with 3. Use Tab and arrow keys to operate sliders. No setup or credentials are needed. For source, open the linked HTML and JavaScript files in the public repository.
